# 语音测试数据同意书

版本 `2026-10-18-v1`。英文版见 [CONSENT.md](CONSENT.md)。录音器页面显示的是同一份文字，并会把一份副本和录音一起保存。

## 用途

随言是开源的 macOS 语音输入法。我们征集大家照着固定脚本朗读的录音，用来**衡量和修复识别准确率**。这些录音只用于测试和比较语音识别，**不会用来训练或微调任何模型**。

## 你会提交什么

- 你录下的每一句一个 16 kHz 单声道 WAV 文件，以及这句的参考文字。
- 在你浏览器里随机生成的参与编号。
- 元信息：口音或地区、麦克风类型（必填，可以选“不愿透露”）；性别、年龄段（选填）。

我们不收集姓名、账号和位置。录音器页面不会上传任何东西：录音只留在你的浏览器里，直到你下载 zip 文件并自己发出。如果你用邮件提交，维护者能看到你的发件地址，只用来回信，不会写进数据集。

声音属于个人信息。请独自录音，不要说出任何私人内容，且仅限年满 18 岁的人参与。

## 授权方式（二选一）

**A. 公开（CC0）。** 我把录音和元信息按 CC0 1.0 贡献到公有领域。它们可能发布在需要申请才能下载的公开数据集里。CC0 无法限制他人的用途，包括用于训练；项目自身只用来做评测。已经被他人下载的副本无法收回。

**B. 仅用于评测。** 我的录音保存在私有数据集中，只供维护者评测准确率，不再分发、不公开，并且在我要求时删除。

## 删除

发邮件到 {{CONTACT_EMAIL}}，附上你的参与编号（在 `manifest.json` 和 zip 文件名里）。选 B：我们会删除你的文件，并在 30 天内回复确认。选 A：我们会把你的文件从数据集中移除，并请有访问权限的人一并删除，但无法保证已经被下载的副本也被删除。

## 自愿参与

你可以随时停止。只要你不发出 zip 文件，任何数据都不会离开你的设备。
