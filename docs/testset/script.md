# 随言准确率朗读脚本

共 90 句，约 10–15 分钟。**用平常说话的语气，一句一句念，句子之间稍停一下；不要读标点符号，编号（如 s01）也不用念。** 念错了可以在录音器里重录，也可以跳过。

同一份脚本的机器可读版本是 [`script.json`](script.json)。录音器里的脚本必须与它一致。

## 三、长句（10 句）

l01. 我昨天下午和设计团队开了一个很长的会，主要讨论了新版本首页的改版方案，大家都觉得需要先把流程简化。
l02. 如果明天上午的天气不太好的话，我们就把户外的活动改到室内，同时提前通知所有参加的同事，免得大家白跑一趟。
l03. 这个季度的销售数据已经整理完了，整体比上个季度有所增长，但是有几个地区的表现不太理想，需要重点跟进。
l04. 我最近在学习如何更高效地安排时间，比如每天早上先列出最重要的三件事，做完之后再去处理其他零碎的事情。
l05. 周末我和朋友约好去郊外徒步，我们打算早上七点出发，中午在山顶简单吃点东西，下午太阳落山之前赶回市区。
l06. 关于新员工的入职培训，我建议把流程分成三个阶段，第一周熟悉公司制度，第二周跟着老员工学习业务，第三周独立完成一个小项目。
l07. 请你把上个月所有的报销单据重新核对一遍，特别是金额比较大的那几笔，确认发票和实际支付记录是一致的，然后发给财务部门。
l08. 我家附近新开了一家咖啡店，环境很安静，咖啡的味道也不错，价格比市中心便宜不少，以后可以在那里写文章或者开线上会议。
l09. 昨天晚上下了一场很大的雨，今天早上路面上还有很多积水，上班路上堵了将近一个小时，所以我可能会比平时晚一点到公司。
l10. 这份项目计划书里关于时间安排的部分还需要再修改，尤其是测试和上线之间的缓冲时间太短了，万一出现问题就来不及处理。
